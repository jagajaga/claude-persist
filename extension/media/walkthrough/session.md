## Sessions live in a daemon

A session is not a tab. The tab is a view onto a session running in a
background process, so closing it, reloading the window, or losing the
connection does not stop the work.

- **Claude Persist: New Session** — pick a folder and start
- **Claude Persist: Open Session** — reopen any session, from any window

Sessions and logs are kept in `~/.claude-persist/`.
