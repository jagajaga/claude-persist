## Signing in

If Claude Code is already set up on this machine, your login is picked up
automatically and there is nothing to do.

Otherwise: **Claude Persist: Add Account (Sign In)**. You get a link to open
and a box to paste the code back into — no terminal, and it works over
code-server where a callback to `localhost` would not.

You can add several accounts and switch between them from the model pill. When
one hits its rate limit the daemon moves to the next and resumes on its own.
